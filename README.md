# Mobile Document Scanner 📱📄

A high-performance cross-platform mobile application built with **Flutter** and **Dart**. This app enables users to capture documents via camera or gallery and convert them into high-quality PDFs instantly.

## ✨ Key Features
* **Camera & Gallery Integration:** Capture or select images for document processing.
* **Instant PDF Generation:** Convert images to formatted PDFs with a single tap.
* **Clean UI/UX:** Built using Flutter Material Design for a seamless user experience.

## 🛠️ Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **Key Plugins:** `image_picker`, `pdf`, `path_provider`

## 🚀 How to Run
1. Clone this repo.
2. Run `flutter pub get`.
3. Use `flutter run` to launch on your device/emulator.
